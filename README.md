# قلّدها إذا تقدر | GALLIDHA

لعبة ويب جماعية لتقليد الأصوات: الكل يسمع صوتًا مرة واحدة، ثم «3… 2… 1… قلّد!» ويسجّل الجميع بنفس اللحظة،
ثم تُعرض التسجيلات بالدور ويحسب الخادم لكل تقليد درجة من 100 بتحليل صوتي حقيقي، ثم عجلة الحظ والتخريب، وأخيرًا التتويج.

- **المايك فقط** — لا كاميرا إطلاقًا (`getUserMedia({ audio, video: false })` + ترويسة `Permissions-Policy: camera=()`).
- عربي افتراضيًا (RTL كامل) مع الإنجليزية من الإعدادات، ويعمل باللمس والماوس والكيبورد، ووضع تطبيق (PWA).
- **النسخة المنشورة**: <https://gallidha.onrender.com> — على Render بشهادة HTTPS حقيقية، فتفتح على الآيفون مباشرة.
  الخطة المجانية «تنام» بعد 15 دقيقة بدون زوار، فأول فتح بعدها يأخذ قرابة دقيقة.

---

## التشغيل

```bash
npm install
npm run dev
```

- على نفس الجهاز: <http://localhost:3200>
- للجوال على نفس الواي فاي: الرابط الآمن الذي يطبعه الخادم، مثل `https://192.168.x.x:3443`
  (المايك في Safari يحتاج HTTPS؛ الشهادة محلية ذاتية التوقيع فيظهر تحذير مرة واحدة: «Show Details» ← «visit this website»).
- رابط الدعوة في اللوبي يتحول تلقائيًا لهذا الرابط الآمن إذا فتح المضيف من `localhost`، ومعه رمز QR.

الإنتاج (نسخة مبنية): `npm run build && npm start`. الإعدادات كلها في [.env.example](.env.example).

| الأمر | الغرض |
| --- | --- |
| `npm test` | اختبارات الوحدة والتكامل (التحليل الصوتي + الغرف عبر Socket.IO) |
| `npm run e2e` | اختبار شامل بمتصفحات Chrome حقيقية (يحتاج `npm run build` أولًا) |
| `npm run calibrate` | معايرة التقييم مقابل تقليدات صناعية لكل الأصوات |
| `npm run packs` | إعادة توليد الأصوات المولّدة (عينات الاختبار) |
| `npm run icons` | توليد أيقونات التطبيق |

## اختبار الآيفون (يحتاج جهازك)

1. شغّل `npm run dev` على الكمبيوتر، والجوال على نفس الواي فاي.
2. افتح في Safari الرابط `https://<IP>:3443` واقبل تحذير الشهادة.
3. اضغط «ابدأ اللعب — تفعيل المايك» ← تظهر نافذة صلاحية Safari/iOS الحقيقية ← سماح.
4. في «اختبار المايك» تكلّم: المؤشر لازم يتحرك، وسجّل 3 ثوانٍ واسمع نفسك.
5. أنشئ غرفة وافتح رابط الدعوة من جهاز ثانٍ، وجرّب: الكتم، الدردشة، جولة كاملة، تحديث الصفحة أثناء اللعب، والمغادرة (مؤشر المايك البرتقالي في iOS لازم يختفي).
6. جرّب الرفض: إعدادات الموقع ← الميكروفون ← رفض، ثم «حاول مرة ثانية» — تظهر تعليمات إعادة التفعيل وخيار المشاهدة فقط.

> إذا كان الأصدقاء على شبكات مختلفة (جوال 4G/5G) فقد تحتاج الدردشة الصوتية خادم TURN (انظر `.env.example`). اللعب نفسه (التسجيل والتقييم) لا يحتاجه لأنه يمر عبر الخادم.

| المقترح | المنفّذ | السبب |
| --- | --- | --- |
| Next.js | **Vite + React** (SPA) + خادم Node واحد | اللعبة تطبيق لحظي بالكامل (Web Audio، WebRTC، WebGL) بدون حاجة لـ SSR أو SEO. خادم واحد يخدم الواجهة والـ WebSocket والـ API، وبناء أسرع. نفس أسلوب ألعابك السابقة |

| Redis | **غير مطلوب** حاليًا | نسخة خادم واحدة تتحمل آلاف الغرف. للتوسع: توجيه كل غرفة لنسخة ثابتة + Socket.IO Redis adapter |

## تقييم التشابه (معالجة إشارة، وليس ذكاء اصطناعي)

يجري على الخادم فقط (العميل لا يرسل أي درجة)، وكل خطوة حتمية وقابلة للاختبار:

1. **فحص الجودة أولًا**: صامت، قصير جدًا، مشوّه (تشبّع)، ضجيج فقط، تالف، أو كان المايك مكتومًا ← حالة «غير موثوق» **بدون رقم مخترع** و0 نقاط.
2. **كشف التشغيل بدل التقليد**: إذا طابق التسجيل الملف الأصلي في الطيف *و* في الطابع الصوتي (MFCC) يُرفض كـ«مشبوه».
3. **محاذاة زمنية DTW** على MFCC والشدة والتسطح الطيفي، ثم خمسة معايير:
   - **النبرات (Pitch contour)**: طبقة الصوت بخوارزمية YIN، ونطرح الوسيط لكل طرف فلا يُعاقب صاحب الصوت العميق أو الحاد على طبقته الطبيعية — المقارنة لشكل اللحن.
   - **الإيقاع**: نمط بدايات النبرات بعد تطبيع المدة، عددها، عدد المقاطع، والدورية.
   - **التوقيت**: المدة الفعلية وتوقيت البدايات بالثواني.
   - **الشدة**: منحنى الطاقة.
   - **الطابع الصوتي**: المسافة الطيفية بعد المحاذاة.
4. **الكلمات لا الهمهمة** (باقة الميمز كلها `"articulate": true`): الهمهمة «ممممم» تتبع اللحن والإيقاع بدقة، فكانت تاخذ ~50. الحين نقيس «انتقالات النطق»: تغيّر توزيع الطاقة على 10 مجموعات ترددية عريضة (≥450Hz لكل مجموعة، فلا تتأثر بطبقة الصوت ولا بلحن الهمهمة) بعد طرح ضجيج الغرفة، كل 40ms، بمسافة Hellinger. الكلام (علّة ← احتكاك ← وقفة ← أنفي) يعطي 4–15 انتقالًا بالثانية، والهمهمة «ممم/أممم/آآآ» 0–3. معيار «الكلمات» شرط يضرب الإجمالي (مو نقاط مجانية): `صرامة(الأداء) × (0.1 + 0.9×الكلمات/100)`.
   - كل ميم له `words` يظهر للاعبين على الشاشة، و`template` = نطق آلي نظيف لنفس الكلمات (`scripts/make-word-templates.cjs`، صوت Piper محلي): نعدّ فيه الانتقالات المطلوبة فلا يُظلم من يغنّي الكلمات ببطء.
   - صوت حروفه قليلة جدًا (صرخة ممدودة مثل «وااااو») يقدر يُستثنى بـ `"articulate": false` فيُقيَّم باللحن والطابع فقط — لكن جرّبناه على «واو الأنمي» وكانت الهمهمة تاخذ أعلى من التقليد الصحيح، فشلناه من الباقة بدل ما نستثنيه.
   - **حدود صريحة**: الخوارزمية تتأكد أنك *نطقت كلامًا فعليًا* بنفس كمية المقاطع والحروف تقريبًا، لكنها لا «تفهم» الكلمات؛ التمييز الدقيق بين كلمة وكلمة يحتاج نموذج تعرّف على الكلام (ذكاء اصطناعي) — جرّبنا مطابقة الطيف بين متحدثين مختلفين وكانت غير موثوقة، فما اعتمدناها.
5. أوزان المعايير قابلة للتعديل لكل صوت في `pack.json` (مثلًا الإيقاع أهم للمهباش، النبرات أهم للصوت الصاعد والهابط).
6. **الصرامة** (`STRICT` في `shared/audio/score.ts`، نوفمبر 2026 بعد ملاحظة «النظام يعطي درجات كبيرة»): «الأداء» المجمّع يتكدّس حول 30–60 حتى للتقليد الضعيف لأن المدة والإيقاع تتشابه بسهولة، فنمدّه خطيًا: 15 أو أقل = صفر، 95 = 100، والمعايير المعروضة بنفس الصرامة. قبلها كان الكلام الغلط ياخذ 33–51.

نتائج المعايرة على الميمز الـ12 (`npx tsx scripts/calibrate-words.ts` ومستويات أخرى) — الوسيط (المدى):

| التسجيل | قبل الصرامة | الحين |
| --- | --- | --- |
| تقليد ممتاز (نفس الأداء بالكلمات، بحنجرة وميكروفون آخر) | 98 | 98 (65–100) |
| تقليد جيد بسرعة مختلفة ±12% | 85–89 | 80–86 |
| تقليد بطيء جدًا (70% من السرعة) | 66 | 46 |
| نص المقطع بس | 50 | 18 |
| الكلمات الصحيحة بدون أداء (قراءة آلية) | 48 | 16 |
| **كلام مختلف** | **38 (33–51)** | **0 (أعلى 36)** |
| همهمة «ممم» و«أممم» و«آآآ» على نفس اللحن والإيقاع بالضبط (أول شي كانت ~50) | 13 | 8 (أعلى 28) |

وتقليدات صناعية بحرف علّة على لحن المقطع (`npm run calibrate`، بدون شرط الكلمات): متقن 85، بصوت عميق 81، بصوت حاد 74، غير متقن (أبطأ ولحن مسطح) 49، صوت مختلف 0.

> المعايرة على تقليدات صناعية؛ مع تسجيلات بشرية حقيقية قد تحتاج `STRICT` أو حدود `CALIBRATION` في `shared/audio/score.ts` تعديلًا بسيطًا. الفرق بين كلمة وكلمة خارج قدرة الخوارزمية (انظر «حدود صريحة» أعلاه)، لكن الكلام المختلف صار ياخذ قليل لأن أداءه (اللحن والإيقاع والتوقيت) مختلف.

## مكتبة الأصوات

باقة «ميمز سعودية» (المجلد `public/packs/trends`): 12 صوت ميم اختيرت بعد بحث (نوفمبر 2026) في موقع أزرار الميمز myinstants.com:

- **سعودية بحتة**: حمودي999 («سلّكت!»، «لو ما في تصوير…»، «بلا بلا بلا»، «عطيه!»)، «استعمل قبضة البعبع!»، طاش ما طاش («الله يحييك»، «ونعم بحالك»)، «لا تقتل المتعة يا مسلم»، «يا عبد الرحمن!».
- **الرائج في السعودية** (قائمة الموقع لما يشغّله السعوديون أكثر، وأغلبها ميمز عالمية): «FAHHH»، «GET OUT!»، «Bruh».
- استبعدنا: أي ميم فيه سب أو إساءة ولو خفيفة (شلنا لاحقًا «أحطك داخل الشاهي… يا هطف» و«يا تيسير يا الحقود»)، والكلام الديني أو السياسي، والأغاني الطويلة، و«واو الأنمي» (تقييمه غير موثوق).
- كل صوت 8 ثوانٍ كحد أقصى (من بدايته، بعد حذف الصمت)، مستوى صوت موحّد −16 LUFS، أحادي 22050Hz. **الحقوق لأصحابها الأصليين.**
- مقاطع الترند التسعة السابقة حُذفت من اللعبة (موجودة في سجل git)، وبقي «القم القم» نسخة ثابتة لاختبارات الوحدة في `tests/fixtures/words`.

الأصوات الثلاثون المولّدة برمجيًا بمحرك اللعبة (`scripts/synth`) صارت عينات ثابتة للاختبارات الآلية في `tests/fixtures/packs` (يعيد توليدها `npm run packs`)، ويمكن إرجاعها للعبة بنقل مجلداتها إلى `public/packs`.

**كلمات المقطع**: أضف للصوت في `pack.json` الحقل `"words": { "ar": "…", "en": "…" }` (يظهر للاعبين)، و`"template": "<id>.words.wav"` (نطق نظيف للكلمات يولّده `scripts/make-word-templates.cjs`).

**إضافة باقة**: مجلد جديد داخل `public/packs/<id>/` فيه ملفات WAV و`pack.json` بنفس صيغة `public/packs/trends/pack.json`، ثم إعادة تشغيل الخادم.

## الخصوصية والأمان

- المايك لا يُفتح إلا بضغطة اللاعب وموافقته، ولا يبث شيئًا تلقائيًا؛ زر كتم واضح في اللوبي وأثناء اللعب، ومؤشر دائم يوضح: شغّال / مكتوم / يسجّل الآن / الدردشة مقفلة.
- **الكتم فعلي**: مسار الدردشة المرسل يُعطّل (يُبث صمت) ومسار التسجيل لا يلتقط شيئًا أثناء الكتم، والمستقبل أيضًا يصفّر صوت أي لاعب مقفول أو مكتوم.
- الدردشة تُقفل تلقائيًا أثناء الاستماع والتسجيل وتشغيل كل تسجيل، وتفتح عند عرض الدرجة للضحك والتعليق.
- مسار التسجيل منفصل عن مسار الدردشة، وإلغاء الصدى مفعّل.
- **سياسة الحذف**: التسجيلات تبقى في ذاكرة الخادم فقط (لا تُكتب على القرص) وتُحذف فور انتهاء عرض الجولة؛ الأجهزة تحتفظ بتسجيلات المباراة في الذاكرة فقط لإعادة «أفضل تقليد» وتُمسح مع بداية مباراة جديدة أو المغادرة. لا يوجد أي زر لتنزيل تسجيلات الآخرين.
- الغرف خاصة بكود من 6 أرقام، ورمز سري لكل لاعب لإعادة الاتصال، والطرد يمنع العودة من نفس المتصفح.
- كل الأحداث يتحقق منها الخادم، وكل النقاط والعجلة تُحسب على الخادم، مع حدود للمعدل.
- كتم عندي، كتم للجميع (المضيف)، إبلاغ (يُحفظ بلا صوت ولا عنوان IP)، وطرد.
- **فلتر الأسماء** (`server/moderation.ts`): الخادم يرفض اسم اللاعب إذا فيه سب أو كلام وسخ (عربي، إنجليزي، عربيزي، ولو ممطوط أو مع «يا/ال»)، واسم الغرفة غير اللائق يصير «غرفة <الكود>»، وتغيير الاسم لكلمة وسخة ما يمشي. القائمة مرمّزة Base64 حتى لا تظهر الألفاظ صريحة في الكود المنشور، والكلمات القصيرة تُمنع ككلمة كاملة فقط حتى لا يُظلم اسم مثل «تيسير» أو «Hassan».
- مغادرة اللعبة أو إغلاق الصفحة توقف كل مسارات المايك فعليًا.

## ما تم اختباره فعليًا وما لم يُختبر

### آليًا (`npm test`: 35 اختبارًا، و`npm run e2e`: 43 فحصًا — كلها ناجحة)

- اختبارات الوحدة: WAV، تحويل المعدل، دقة كشف طبقة الصوت (85–1000Hz)، عد البدايات، حالات «غير موثوق»، التقليد المتقن > غير المتقن > الصوت الخاطئ، العدالة للأصوات العميقة والحادة، كشف تشغيل الملف الأصلي، مؤثرات التخريب، والهمهمة على نفس اللحن تاخذ أقل من 20 بينما الكلمات نفسها بأي صوت وسرعة تاخذ «كلمات» ≥80.
- تكامل عبر Socket.IO: مباراة كاملة، وضع الضحك، إعادة الاتصال، نقل المضيف، الطرد ومنع العودة، تمرير إشارات WebRTC داخل الغرفة فقط، السرية (لا درجة ولا نوع تخريب قبل وقته)، خروج لاعب لا يلغي المباراة.
- متصفحات Chrome حقيقية (كمبيوتر + محاكاة iPhone 13)، ثلاثة لاعبين في ثلاثة متصفحات:
  - رفض الصلاحية، و NotFoundError و NotReadableError و OverconstrainedError، والمشاهدة بدون مايك.
  - طلب الصوت فقط (`video: false`) ومنع الكاميرا بالترويسة.
  - الدخول برابط الدعوة وبالكود، واتصال WebRTC صوتي مباشر.
  - **الكتم فعلي في الشبكة**: الصوت الواصل من لاعب مكتوم = 0، وأثناء التسجيل = 0.
  - التسجيل الحقيقي من المايك ← الرفع ← التقييم على الخادم ← التشغيل عند الجميع (تقليد البقرة 99، صوت خاطئ أقل، المايك الصامت = «صامت» بلا درجة).
  - تزامن النقاط بين الأجهزة، العجلة، التتويج، إعادة الاتصال بعد تحديث الصفحة، وإيقاف المايك عند المغادرة.
  - المكتبة (كل أصواتها ملفات WAV حقيقية)، التدريب الفردي، التبديل للإنجليزية، «العب الآن».

> في اختبار المباراة يُغذّى المايك بتقليد صناعي عبر مسار Web Audio (بدل إنسان)، وكل ما بعده هو كود اللعبة الحقيقي. مسار المايك الوهمي لـ Chrome نفسه مختبر في سيناريو الصلاحيات.

### لم يُختبر (يحتاج أجهزتك أو خدمات خارجية)

- **iPhone Safari عبر HTTPS على جهاز حقيقي** — غير متاح في بيئة التطوير؛ الخطوات أعلاه.
- Android حقيقي، وأداء الرسوميات ثلاثية الأبعاد على الجوالات الضعيفة (يوجد وضع «خفيف» و«بدون 3D»).
- الدردشة الصوتية بين شبكات مختلفة عبر الإنترنت (قد تحتاج TURN).
- تخزين البلاغات في PostgreSQL (لا توجد قاعدة بيانات هنا؛ الافتراضي ملف ومُختبر).
- دقة التقييم مع تقليدات بشرية حقيقية للميمز، ومقياس «الكلمات لا الهمهمة» مع همهمة وكلام بشري حقيقي — معايرته على أصوات آلية (Piper وWindows) وهمهمة مولّدة.
